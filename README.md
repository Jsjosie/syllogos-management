# Syllogos Management

A web-based management application for organizing and managing members of an association.

The project was developed with Laravel and focuses on implementing a complete CRUD workflow, authentication, database management and a simple responsive user interface.

## Features

- User authentication
- Member management
  - Create members
  - Edit member information
  - Delete members
  - View member list
- Search members by name, phone or email
- Filter members by active / inactive status
- Pagination
- Form validation
- Responsive user interface

## Tech Stack

- PHP
- Laravel
- MySQL / SQLite
- Blade
- Tailwind CSS
- Alpine.js
- Vite
